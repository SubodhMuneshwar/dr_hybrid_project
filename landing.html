About Us

Project Overview

The Diabetic Retinopathy Detection system is an innovative tool designed to assist in the early detection of diabetic retinopathy using artificial intelligence and machine learning. This project combines medical imaging analysis with state-of-the-art deep learning models.

Our Mission

To provide accessible, accurate, and user-friendly tools that support healthcare professionals in identifying diabetic retinopathy at early stages, potentially preventing vision loss and improving patient outcomes.

Technology Stack

  • Backend: Python, Flask, TensorFlow, Keras
  • Frontend: HTML, CSS, JavaScript
  • ML Models: Convolutional Neural Networks (CNNs) trained on retinal imaging datasets
  • Image Processing: OpenCV, scikit-image
  • Data Analysis: NumPy, Pandas, scikit-learn

Classification System

Our system classifies retinal images into 5 categories:

  • Class 0 - No DR: No signs of diabetic retinopathy
  • Class 1 - Mild DR: Mild microaneurysms present
  • Class 2 - Moderate DR: Moderate hemorrhages and hard exudates
  • Class 3 - Severe DR: Multiple hemorrhages and venous beading
  • Class 4 - Proliferative DR: Neovascularization and retinal detachment risk

Dataset and Training

The model was trained on publicly available diabetic retinopathy datasets and validated with rigorous testing protocols to ensure accuracy and reliability.

Note: This tool is a demonstration of AI capabilities in medical imaging. Results should always be verified by qualified healthcare professionals before any clinical decisions are made.
